# TV Disk

Flash diski eski televizyonların okuyacağı biçime getiren Android uygulaması (Erkam Yazılım).

- **TV'ye Uyumlu Yap:** USB belleği root gerekmeden MBR + FAT32 olarak formatlar (Güvenli 32 GB ya da tam kapasite).
- **Video Ekle:** Videoyu kontrol eder; TV'ye uygunsa kopyalar, değilse MP4 (H.264 720p + AAC) biçimine dönüştürüp diske koyar.

İndir: https://github.com/mitturkeyhack/TV-Disk/releases/latest/download/TV-Disk.apk
